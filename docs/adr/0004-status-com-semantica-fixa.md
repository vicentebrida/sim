# Status da Ideia têm semântica fixa; só a aparência é personalizável

Os Status carregam regras de domínio (Duplicada migra Curtidas e Seguidores, Arquivada sai da listagem, Recusada exige justificativa, Em análise trava a edição do Autor). Por isso o conjunto de Status é fixo no código: o Administrador pode renomear o rótulo, mudar cor e descrição, e desligar os opcionais (Rascunho, Aprovada, Em execução), mas não criar Status novos. Workflow configurável foi rejeitado porque o sistema não saberia como um Status arbitrário se comporta; se houver demanda, a extensão prevista é subetapas dentro de Em execução.

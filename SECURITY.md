# Política de segurança

## Versões suportadas

Enquanto o SIM não tiver uma versão 1.0, apenas a versão mais recente do branch `main` recebe correções de segurança.

## Como reportar uma vulnerabilidade

**Não abra uma issue pública.** Use o recurso [Private vulnerability reporting](https://docs.github.com/pt/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) do GitHub, na aba _Security_ do repositório.

Inclua, se possível: versão afetada, passos para reproduzir, impacto esperado e sugestão de correção. Responderemos em até 7 dias.
